# Âm "Bộ máy Thiên Cơ" (ThienCoHook)

Tổng hợp bằng `python3 Tools/Audio/make_thienco_clockwork_sfx.py` (numpy, hạt giống cố định, không mẫu → không vướng bản quyền).
WAV mono 44,1 kHz 16-bit. **CHƯA AI NGHE THỬ.** `ThienCoFxSetup` tự điền vào prefab ThienCo_Fx.

tick/tock (bộ thoát), wind (lên dây cót), gear_clank (bánh răng chạm), mesh_ok (ăn khớp), jam (kẹt răng), bell / bell_big (chuông),
sproing (lò xo bung), winddown (hết dây cót – kết bậc Rác), cuckoo / cuckoo_sad (chim cu), launch (rương bật lên), sand_loop (cát), musicbox_rise (hộp nhạc dâng).
