# Âm kịch bản "Loa Bass Kẹo Kéo" (Chest_AmNhac)
Tổng hợp bằng `python3 Tools/Audio/make_amnhac_sfx.py` (numpy, hạt giống cố định, không mẫu → không vấn đề bản quyền).
WAV mono 44,1 kHz 16-bit. **Chưa ai nghe thử.** kick/hat/clap/wub = nhịp; scratch/skip = bấm B; needle = đĩa vào mâm;
riser = trước khóa; drop/horn = bậc cao; recordstop/deflate/plugpop = Rác (và "pụp" Thường); wheels/feedback = loa kẹo kéo.
